# 协议离婚与诉讼离婚

先分流：双方是否都同意离婚？对子女、财产、债务是否能达成一致？

协议离婚：核验现行登记程序、离婚冷静期、申请/撤回/登记期限、离婚协议内容与执行风险。

诉讼离婚：整理感情破裂相关事实、分居、家暴、重婚/同居、赌博吸毒等事实（如有）、既往诉讼情况；同步处理财产、债务、子女、损害赔偿、保全。

既往已有离婚案件时，先确认法律文书类型、裁判结果、送达日期、生效日期及此后的共同生活/分居情况，不把“开过庭”“第一次没判离”当作足够精确的程序事实：

- 一审判决仍在法定上诉期内：核验现行上诉期限，评估是否针对事实认定、证据评价或法律适用提出上诉。
- 判决不准离婚已经生效：核验再次起诉的受理限制，以及《民法典》第一千零七十九条关于判决不准离婚后又分居满一年、再次起诉的规则。
- 撤诉、按撤诉处理、调解和判决不准离婚不是同一种结果，分别核验重新起诉规则。
- 分居年限不是自动离婚条件。区分总分居时间、因感情不和分居、连续性，以及第一次判决生效后的新增分居期间。

不得承诺“一次一定判离”或用固定时间预测具体法院结果。
