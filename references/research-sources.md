# 官方法源与检索优先级

优先级：
1. 全国人民代表大会/中国人大网：法律正文与修法信息。
2. 中国政府网、国家行政法规库、司法部：行政法规及政府规范。
3. 最高人民法院：司法解释、答记者问、指导性/典型案例、裁判规则说明。
4. 最高人民检察院、公安部、民政部等：职责范围内规范与权威说明。
5. 地方高级人民法院/政府部门：仅用于补充本地规则或公开案例，不替代全国性法源。

V1.0 关键更新：
- 婚姻家庭编司法解释（二）：法释〔2025〕1号，2025-02-01施行，共23条。
- 修订后的《婚姻登记条例》：国务院令第804号，2025-05-10施行。

检索要求：
- 用户问“现在”“最新”“目前能不能”等，必须先核验现行规则。
- 引用法条前核对条号和文本。
- 典型案例只能作为理解裁判规则的辅助，不得冒充普遍必然结果。
